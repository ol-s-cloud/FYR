# Find Your Religion®

Independent Next.js commerce platform for FYR: self-care, athletics, uniform, limited editions and objects for sovereign individuals.

## Model
- Curated: supplier-backed products tested for demand and quality.
- FYR Editions: proprietary, limited and eventually handmade/handwoven pieces.
- Supplier integrations remain adapter-based so FYR is never dependent on one fulfilment provider.

## Current phase
Brand/storefront foundation. Next: product detail routes, cart, Stripe, persistence, CJ supplier adapter, margin engine, Pinterest/Meta/Google feeds and analytics.

## Run
npm install
npm run dev

## Principles
No fabricated reviews, scarcity, materials or discounts. Supplier products must pass FYR body / ritual / uniform / objects selection rule before publication.
